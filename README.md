# VPN Server Panel

Самостоятельный VPN-роутер на Ubuntu: сервер с двумя (и более) сетевыми картами раздаёт локальной сети интернет исключительно через VPN-туннель, а управляется через веб-панель.

## Что внутри

| Каталог | Что это |
|---|---|
| [`installer/`](installer/) | Установщик `install.sh`, диагностика `diagnostic.sh` и документация к ним |
| [`panel/`](panel/) | Веб-панель (PHP 8 + vanilla JS), демон отказоустойчивости, деплой и маршрутизация каналов |

Подробности — в [installer/README.md](installer/README.md) и [panel/README.md](panel/README.md), диагностика по секциям — в [installer/docs/diagnostic.md](installer/docs/diagnostic.md).

## Установка

Нужны Ubuntu 22.04/24.04 и минимум две сетевые карты: одна смотрит к провайдеру (WAN), вторая — в локальную сеть (LAN).

```bash
git clone https://github.com/linux0programmer/vpnpanel.git
sudo bash vpnpanel/installer/install.sh
```

Если на сервере нет доступа к GitHub — скопируйте каталог проекта любым способом и запустите `installer/install.sh` из него: панель возьмётся из соседней папки `panel/`, сеть для установки не нужна.

Установщик спросит, какие карты использовать, предложит добавить резервных провайдеров и даст выбрать режим WAN: DHCP, статика или **оставить текущие настройки** — последнее удобно, когда сеть уже настроена и трогать её нельзя.

## Что делает панель

- **VPN-менеджер** — несколько конфигов WireGuard и OpenVPN, приоритеты, переключение, автоматическое восстановление
- **Kill Switch** — политика `FORWARD DROP`, локальная сеть физически не может выйти мимо туннеля
- **Несколько провайдеров** — список каналов с приоритетом, policy routing по таблице на канал, переключение при отказе линии
- **Мониторинг** — нагрузка, скорость и трафик по интерфейсам, журнал событий
- **Диагностика и консоль** — пинг через выбранный интерфейс, веб-терминал
- **Обновления** — по тегам, со снимком перед выкладкой и автоматическим откатом при провале проверки
- **Управление парком** — панели раз в час читают `release.conf` из репозитория: там задаётся тег релиза, стоп выкатки, процент канарки и откат всего парка

## Обслуживание

```bash
sudo vpn-panel-deploy check          # что развёрнуто, что доступно, что говорит манифест
sudo vpn-panel-deploy deploy         # обновиться немедленно
sudo vpn-panel-deploy rollback       # вернуться на предыдущий снимок

sudo vpn-panel-routing status        # каналы в интернет и их состояние
sudo vpn-panel-routing add-wan ens36 # добавить провайдера без переустановки

sudo bash diagnostic.sh              # ~80 проверок состояния сервера
```

Ключевые настройки сервера лежат в `/etc/vpn-panel.conf`: интерфейсы, список каналов, параметры локальной сети, канал обновлений. Что разворачивать на всём парке — в [`release.conf`](release.conf).
